# Image Prompt Batch Prompt

Turn approved image concepts into production-ready image prompts.

For each post, preserve:

- Post ID
- Date
- Brand/business
- Platform
- Campaign
- Content pillar
- Asset filename
- Alt text

Image style:

- Clean, practical, professional
- Relevant to small business operations and content workflows
- No readable text inside generated images
- Avoid stock-photo cliches
- Leave space for optional platform crop adjustments

Return as CSV with:

```text
post_id,date,brand_business,platform,asset_filename,image_concept,image_prompt,alt_text
```
